# TracePad

TracePad is a small browser-based notebook for keeping debugging investigations together.

## Use it

Open `index.html` in a modern browser. No server, account, database, framework or Docker is required.

Each entry can hold:
- A short title and context.
- Reproduction steps.
- A current hypothesis, including what might disprove it.
- Evidence collected.
- Outcome or next action.

Entries are saved in `localStorage` for the current browser profile. Use **Export JSON** to save a portable copy of your notes.

## Privacy and limitations

There is no cloud sync, collaboration, encryption layer or automatic backup. Data can be lost if browser site data is cleared or the browser profile changes. Do not enter passwords, customer details, internal URLs, private code or other sensitive information.

The sample fields are a working note-taking format, not a replacement for an issue tracker or incident record.
