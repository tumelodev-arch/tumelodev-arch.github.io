INDEPENDENT TOOLS / LIVE DEMOS

Small products with useful jobs to do.

These are working browser applications, not screenshot-only mock-ups. Each has a distinct use case, real interactions, local persistence and export paths. They run without a server, sign-in or third-party runtime dependency.

i

Before you start. The tools store data in your current browser only. Sample records are synthetic. There is no cloud sync, bank connection, live monitoring, or shared workspace. Do not enter confidential or sensitive data.

ENGINEERING STANDARD

Useful first. Verifiable always.

Each tool has a clear boundary and no claim to backend features it does not have. Their source includes input validation, accessible labels and empty states, persistence failure handling where relevant, and export functionality that can be inspected. They are small independent applications, ready for further tests and service integrations as the next step.
