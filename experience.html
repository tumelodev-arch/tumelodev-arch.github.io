EXPERIENCE / ENGINEERING PRACTICE

Building software is only part of the job.

I'm a junior software engineer focused on backend development, cloud platforms and production systems. My work spans feature delivery, investigation, validation, quality and the practical steps that move a change safely through a team.

PROFESSIONAL SUMMARY

Junior software engineer focused on .NET backend development, cloud platforms and production systems. Experienced in building and supporting business software, investigating complex defects, implementing validation and business rules, and improving engineering quality through testing and review.

01 / WHAT THE WORK INVOLVES

Responsibilities and technical themes.

01

Backend features and business rules

Develop and support .NET services and CQRS-based applications. Work with validation frameworks, request handling, business rules and backend behaviour that supports customer-facing functionality.

TECHNICAL CONTEXT

C# · .NET · ASP.NET Core · CQRS · REST APIs · SQL

02

Defect investigation and production support

Investigate complex issues by reproducing behaviour, tracing request or data paths, reviewing evidence and verifying whether a fix addresses the reported outcome. Work includes customer-impacting defects and submission/validation failures.

INVESTIGATION PRACTICE

Root-cause analysis · Debugging · Logs · Regression checks · Production verification

03

Testing and engineering quality

Use unit, negative, validation and regression tests to make expected behaviour explicit. Review changes, respond to feedback and check edge cases where invalid or unexpected input matters.

QUALITY PRACTICE

Unit tests · Negative testing · Validation tests · Pull requests · Code review

04

Cloud platforms and distributed systems

Hands-on exposure to AWS services and cloud-hosted workloads, including container workloads and managed data services. GameDay exercises have involved diagnosing service routing, task failures, resource issues and deployment behaviour in distributed environments.

AWS SERVICES NAMED

ECS · Fargate · DynamoDB · EC2 · Load Balancers · CloudWatch

05

Security-minded development

Participate in security reviews and remediation discussions. Focus areas include identifying risky input handling, checking authorisation assumptions and assessing how application behaviour could be abused.

REVIEW TOPICS

SSRF · CSV formula injection · Authorisation review · Password hashing assessment
